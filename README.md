# Kayaking Adventure Website
This is a modern, responsive website built for a local kayaking business.

## Features
* **Floating Contact Icons:** Easy access to WhatsApp and Instagram.
* **Interactive Map:** Shows the exact location of the kayaking spot.
* **Auto-Scrolling Gallery:** A smooth, "river-like" flow of images.
* **Responsive Design:** Optimized for both mobile and desktop users.

## Technologies Used
* HTML5
* CSS3
* Font Awesome (for icons)
* Google Fonts (for modern handwriting typography)
